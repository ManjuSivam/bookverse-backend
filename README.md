# 📚 BookVerse Backend

BookVerse Backend is a production-inspired bookstore backend system built using Spring Boot, designed with scalable enterprise application architecture principles.

The project focuses on clean layered architecture, modular design, RESTful APIs, validation, security, async processing, retry handling, observability, and future-ready microservices evolution.

## 🚀 Current Features

- Book & Category Management
- RESTful APIs
- DTO & Mapper Pattern
- Validation & Exception Handling
- Layered Architecture
- MySQL Integration
- Spring Data JPA
- CORS Configuration

## 🧠 Engineering Focus Areas

- Clean Architecture
- Separation of Concerns
- Modular Monolith Design
- JWT Authentication & Authorization
- Event-Driven Architecture
- Retry & Concurrency Handling
- Structured Logging & Traceability
- Microservices Migration Strategy

## 🛠️ Tech Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- Apache Kafka
- Apache ActiveMQ
- Maven
